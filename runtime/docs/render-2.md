# X360 renderer features, widescreen, antialiasing, display changes (part 2 of 6)

Part of the runtime documentation; the index and switch lookup hint are in `runtime/README.md`.

- Tunnel reverb hold (port extra,                                                   `NFS_TUNNEL_REVERB_HOLD=<seconds>`, default 0.3, `0` = retail; env only, no F10 row; both reverb modes): retail `SFXCTL_Tunnel::UpdateIsInTunnel` (004C5C00) calls `SetCurrentReverbType` (004B57E0) on every zone in/out flip with no hysteresis, so short tunnels and zone-4 stretches flicker (in 6 frames, out 18) and every flip restarts the 120/300 ms fade and cuts the FX tail (user log: 155 of 200 small-tunnel entries < 15 frames). The hook (`x360audio.c`, state in `tunnelhold.h`) keeps the tunnel type for the hold in sim time after a leave; entering is immediate and a re-entry with the held type does nothing; any other caller (city zone change, EndTunnelVerb) applies at once. BOOT_DIAG `tunnel reverb type ... HELD / HOLD ABSORBED / hold over` lines. Test: `runtime/tunnelhold_test.py` (hold 0.3 -> 2 applied changes on a flicker sequence, retail 0 -> 22, fails). Race 10.2.1 autodrive, f300-4900: game calls 36 both; applied 5 with the hold vs 36 retail, FX patch sets 6 vs 18.
  Alley (`AAB5B207`), Hills (`3A0F2F2C`) and Simple_Tunnel (`8F11660F`) retain their PC mono/stereo records and append the X360 quad records: 468/444/420 bytes. The retail selector uses quad for four/six-channel output and PC fallback for forced mono/stereo. Simple_Tunnel_Sml (`BFFFF2FA`, 256 bytes) uses the X360 mono/stereo blob, whose only changes are low-pass Q8 gains 256 -> 217 at +0xA2/+0xAA. `BOOT_DIAG` prints `x360reverb: preset <key> merged PC=<bytes> X360=<bytes> bytes=<merged>` for all four keys and an `x360audio:` summary with map/preset counts and total bytes. Inputs on disk stay unchanged.
  Offline proof: `"$TOOLS_PY" -I runtime/x360reverb_test.py`. A native ASan/UBSan harness (`x360reverb_test.c`) extracts 58 translated retail functions, including selector `008215FC`, parser `00821108`, renderer `00820DA3` and the scalar mixer, and loads constants/routing tables from the retail PE. Only guest allocation/free and indirect dispatch are harness infrastructure; no second DSP implementation, game process, audio device or Unicorn. Tests cover default/env/saved/restart settings, independent mix/reverb opens, all 25 directory entries, malformed/missing extract fallback, and 12 exact selected payloads across 1/2/4/6 channels. Ten-second impulses at 44.1/48 kHz require exact merged/raw-X360 responses for quad/six-channel output, PC mono/stereo fallback equality for the first three presets, finite peaks below 1, last-second energy below 1e-10 of total, independently predicted channel onsets (including silent LFE), and energy/decay changes. The script retains float responses, fixed-gain PCM16 WAVs, diagnostics and negative-control logs in the scratch directory it prints. Input impulse is 0.25; WAVs use the same gain for listening.
